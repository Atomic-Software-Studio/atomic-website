# Brand source — drop files here

Working folder for the real logo files. Not served to the browser; production
assets get generated from these into `public/brand/` and the components.

Delete nothing that lands here — this becomes the source of record that
`logo_full.png` never was.

## Send whatever you have. Best first.

### 1. Vector (ideal — one of these is enough)

    atomic-mark.svg          the atom mark alone
    atomic-lockup.svg        mark + ATOMIC + software studio, as it is really locked up

Also fine, and just as good: `.ai`, `.eps`, `.pdf`, or a Figma share link.

Export notes if you control the export:
  - text converted to outlines
  - no embedded raster images
  - viewBox present; width/height attributes can be removed
  - do not "simplify" or flatten the gradient

### 2. Raster (only if no vector exists anywhere)

    atomic-mark@1024.png         mark alone, 1024x1024, transparent
    atomic-lockup@2400.png       lockup, >=2400px wide, transparent
    atomic-lockup-light@2400.png light version, if the artwork differs on dark

PNG-24 with alpha. Do not upscale a small file — send the largest original.

### 3. Specs (short answers are fine)

    gradient start hex + end hex, and its direction
    wordmark colour(s) - is "studio" gradient or flat?
    typeface for ATOMIC, and for software studio
    clear space + minimum size rules, if any exist
    anything in the mark I got wrong (orbit angles, the outer ring gap, electron positions)

### 4. Where it was made

Canva / Figma / Illustrator / something else — sometimes the vector is
recoverable from the tool even when the file is lost.
